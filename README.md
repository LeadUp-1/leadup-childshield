## 📌 Overview

LeadUp ChildShield is an *early warning system* that protects Nigerian children from climate-related health risks. It connects community volunteers, PHC workers, and school representatives into a unified reporting and alert platform.

*This repository contains a UX simulation* – a fully interactive, clickable prototype demonstrating the intended user experience of the proposed system.

---

## 🎯 Problem We Solve

In Nigeria today:
- 🌊 *Flooding* → Waterborne diseases, drowning, displacement
- 🔥 *Extreme heat* → Dehydration, heatstroke, school closures
- 💧 *Unsafe water* → Diarrhea (2nd leading cause of child death)
- 🦟 *Climate-sensitive diseases* → Malaria, cholera outbreaks
- 📉 *School absenteeism* → Disrupted education, child protection concerns

*The core problem:* These signals exist but remain disconnected. No system links community reports to health facilities, schools, or the authorities who can act.

*LeadUp ChildShield closes this gap.*

## 🚀 Key Features (Demonstrated in Prototype)

| Feature | Description |
|---------|-------------|
| 📝 *Reporting Form* | 6 climate-health issues (flooding, heat, unsafe water, diarrhea, malaria, absenteeism) |
| 🧠 *AI Risk Scoring* | Simulated ML pattern recognition and predictive analytics |
| 📊 *Dashboard* | Real-time risk visualization, interactive map, KPI metrics |
| 🔔 *Alert Inbox* | Priority-coded alerts with actionable guidance |
| 🏢 *Authority Alerting* | Automatic routing to responsible agencies (NEMA, NCDC, etc.) |
| ⏱️ *Escalation* | Unacknowledged alerts escalate to higher authorities |
| ✅ *Community Verification* | Reporters verify resolution before alerts close |
| 📱 *SMS/WhatsApp Simulation* | PHC communication center with message templates |
| 👁️ *Oversight Dashboard* | Agency performance tracking, follow-up tasks, reports |
| 📤 *Data Export* | CSV export for open data compliance |

## 🏛️ Accountability Framework

LeadUp ChildShield includes a *multi-level accountability system*:

| Level | Oversight Agencies | Function |
|-------|-------------------|----------|
| *Federal* | NPHCDA, NMEP, Federal Ministry of Women Affairs | Monitor national response, escalate, generate reports |
| *State* | State Health Ministries, SPHCDA, SUBEB | Direct oversight, resource allocation |
| *Local* | LGA Chairmen, Local WASH Units | First-line response |
| *Community* | Volunteers, PHC workers, schools | Report, verify resolution |

*Every alert is tracked. Every authority is measured. Every delay is visible. Every resolution is verified.*
